## الدخول إلى حساب العضو|Sign in as a member
افتح تطبيق أعضاء النادي أو رابط /member على الموقع. أدخل رقم الموبايل المسجل والرقم السري؛ لا تستخدم حساب إدارة النادي.|Open the Members app or the site's /member page. Enter your registered mobile and PIN; do not use a club-management account.
الحساب الجديد يطلب تغيير الرقم المؤقت قبل عرض البيانات. إذا تعذر الدخول اطلب من إدارة ناديك مراجعة رقم الهاتف وإعداد دخولك.|New access requires changing the temporary PIN before showing records. If sign-in fails, ask club management to check your phone and access setup.
## الملخص والكارت|Home summary and entry pass
الملخص يعرض العضوية والحضور الأسبوعي والرصيد والحجز القادم بحسب بيانات ناديك. افتح الكارت أو البرنامج أو التواصل مباشرة من الأزرار المتاحة.|Home shows membership, weekly attendance, balance and the next booking from club records. Open your pass, program or conversation using the available direct buttons.
افتح كارت الدخول عند القارئ وفق تعليمات النادي. عرض الكارت وحده لا يثبت تسجيل الحضور؛ انتظر تأكيد النظام أو الموظف المخول.|Show the entry pass at the scanner under club instructions. Displaying it alone does not prove a check-in; wait for system or authorized-staff confirmation.
## البرنامج والحصص والتواصل|Program, classes and contact
افتح التدريب واختَر اليوم ثم التمارين. راجع تعليمات المدرب ولا تعتبر البرنامج تشخيصًا أو علاجًا.|Open Training, select the day and then exercises. Follow your coach's guidance; the program is not a diagnosis or treatment.
راجع حالة الحجز والانتظار قبل الذهاب للحصة. استخدم التواصل الخاص مع النادي عند وجود خطأ في البيانات أو الرصيد.|Check booking and waitlist status before attending a class. Use private club contact for record or balance errors.
## حدود واجهة العضو|Member-interface limits
واجهة العضو لا تعرض لوحة الإدارة أو كشوف كل المتواجدين أو بيانات الأعضاء الآخرين. التبسيط الإداري يظهر للمالك والموظف المصرح فقط.|The member interface does not expose management, the full current-presence roster or other members' records. Administrative simplification is for authorized owners/staff.
البيانات المعروضة دون اتصال قد تكون من آخر تحديث؛ اتصل وحدث قبل الاعتماد على حالة العضوية أو الحجز الحالية.|Offline information may reflect the last refresh. Connect and refresh before relying on current membership or booking status.
## الويب وWindows والموبايل|Web, Windows and mobile
الواجهة المنشورة مشتركة مع Windows وتطبيقات Android التي تفتح الموقع. أغلق التطبيق وافتحه وأنت متصل لتحميل الواجهة الحالية؛ التثبيت وحده لا يمنح صلاحية.|The hosted interface is shared by Windows and Android shells. Close and reopen online to load the current interface; installation alone grants no access rights.
الحزمة الحالية تتضمن Windows 1.1.15 محليًا وGymEG Android الإدارة والأعضاء 1.1.5 ودعم Android 1.0.4. يوجد أيضًا APK بديل للحزم الأقدم مع الحفاظ على توقيعها. iPhone تطبيق ويب قابل للتثبيت. Windows غير موقع Authenticode؛ اختبار الهاتف الفعلي والنشر الجديد لم يكتمل.|This bundle contains locally built Windows 1.1.15, GymEG Android Manager/Members 1.1.5 and Support 1.0.4, plus legacy-package updates retaining their signing identity. iPhone is an installable web app. Windows is unsigned; physical-phone acceptance and the new deployment are incomplete.
على iPhone افتح رابط الخدمة المناسب في Safari ثم أضف إلى الشاشة الرئيسية. هذه واجهة ويب قابلة للتثبيت، ولا تحتوي الحزمة ملف IPA أو إصدار App Store.|On iPhone open the appropriate service link in Safari and Add to Home Screen. This is an installable web interface; the bundle contains no IPA or App Store release.
## التحقق وحدود التسليم|Verification and delivery limits
تم التحقق من دمج هوية GymEG في PR50. تضم الحزمة إصلاح الحجز المحلي وتحديثات التوثيق بتاريخ 3 نوفمبر 2026. لا تعني الحزمة تفعيل النطاق أو اكتمال النشر؛ راجع تقرير الحالة.|The GymEG identity in PR50 is merged. This bundle adds the local reservation fix and documentation updates dated 3 November 2026. Packaging does not prove domain activation or completed deployment; read the status report.
نتيجة المراجعة المحلية: 276 اختبار وحدة ناجحًا و7 اختبارات اختيارية متصلة بقاعدة البيانات متخطاة، ونجحت 15 مجموعة تكامل. نجح فحص الأنواع والتنسيق وبناء الإنتاج. تطبيقات Android الأصلية وPush الخلفي على الأجهزة لم تُختبر فعليًا؛ التفاصيل في دليل تنبيهات رسائل النادي.|Local audit: 276 unit tests passed with seven optional database tests skipped, and all 15 integration suites passed. Typecheck, lint and the production build succeeded. Native Android apps and background Push have not been tested on devices; see the Club Message Alerts guide.
لا تمثل هذه النتائج اختبارًا فعليًا لكل شاشة أو قارئ أو كاميرا أو طابعة على أجهزة العملاء. المعاينة البصرية لتقارير التطبيق الفعلية والتشغيل المالي الحقيقي غير مؤكدة.|These results do not certify every screen, scanner, camera or printer on customer devices. Visual acceptance of actual application exports and real financial operation remains unverified.

## اشتراكك الرياضي مستقل|Your fitness membership is separate
عضويتك الرياضية وأسعارها ومدتها يحددها النادي. اشتراك إدارة التطبيق أو إعفاء صاحب المنصة منه لا يغيّر رصيدك أو فاتورتك أو مدة عضويتك.|Your club sets fitness membership price and duration. The management app's subscription or the platform owner's exemption does not change your balance, invoice or membership term.

## تحديث هوية GymEG والتطبيقات|GymEG identity and application update
اسم النظام GymEG، وتطبيقا الموبايل GymEG Manager وGymEG Members، وتطبيق الكمبيوتر GymEG Desktop. الرابط المستهدف https://gymeg.vercel.app. راجع تقرير التسليم لتأكيد حالة تفعيله الفعلية.|The product is GymEG, with GymEG Manager, GymEG Members and GymEG Desktop. The target is https://gymeg.vercel.app. Check the delivery report for its verified deployment status.
توقيع Android جديد بموافقة المالك. لا تثبت النسخة فوق PUSHTORQ القديم: زامن العمل المعلق، ثم أزل القديم وثبت الجديد وسجل بحسابك الحالي. بيانات الخادم باقية. iPhone يستخدم Safari ثم إضافة إلى الشاشة الرئيسية.|Android uses a new owner-authorized certificate. Sync pending work, uninstall the old PUSHTORQ app, install GymEG and sign in with your existing account. Server records remain. On iPhone use Safari and Add to Home Screen.
لا تتضمن حزمة العملاء مفاتيح التوقيع أو كلمات مرور الخدمات. نسخة Windows غير موقعة Authenticode حاليًا؛ مسار Microsoft Store يحتاج حساب ناشر وقبول الحزمة. الأجهزة الفعلية لم تُختبر ضمن تغيير الهوية.|Customer packages exclude private keys and service passwords. Windows is currently unsigned with Authenticode; the Microsoft Store path requires a publisher account and package acceptance. Physical hardware has not been tested as part of this rebrand.
## تنبيهات رسائل النادي|Club message alerts
من صفحة إعلانات النادي ورسائلي اضغط تفعيل تنبيهات الرسائل واسمح بالإشعارات. بعد نشر Push يمكن للمتصفح المدعوم عرض التنبيه عندما تكون الصفحة مغلقة. لا يحتوي التنبيه نص رسالتك.|In Club updates & my messages, select Enable message alerts and allow notifications. Once Push is deployed, supported browsers can show alerts when the page is closed. Notifications never show your message text.
على iPhone أضف الموقع إلى الشاشة الرئيسية من Safari ثم فعّل الإشعارات. تطبيق Android الأصلي يحتاج تحديثًا منفصلًا لتلقي Push عند إغلاقه.|On iPhone, add the site to the Home Screen from Safari, then enable notifications. The native Android app needs a separate update to receive Push while closed.
