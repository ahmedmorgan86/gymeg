## ما عولج

- أضيف `npm run release:check` للتحقق آليًا من تطابق رقم الإصدار ورقم البناء ومعرّف الحزمة في Android Manifest مع بيانات APK، وحجم الملف وبصمة SHA-256، وإصدار Windows المسجل.
- أضيف فحص اتساق الإصدار إلى GitHub Actions.
- حُدّث README ليبين إصدارات Windows وAndroid الحالية، ويفصل تطبيق iPhone القابل للتثبيت من Safari عن تطبيق IPA أصلي.
- حُدّثت مصادر الأدلة ثنائية اللغة بإصدارات Android الصحيحة وبالوصف الدقيق لحالة Firebase Push: التكامل موجود في المصدر والحزم، والتسليم على هاتف فعلي لم يُعتمد بعد.
- أُعيد إنشاء الأدلة السبعة ثنائية اللغة بتاريخ 5 نوفمبر 2026، ورُندرت الصفحات الـ92 لمراجعة التخطيط والنصوص بصريًا.
- لم تتغير قواعد بيانات الإنتاج أو إعدادات الخدمات أو سجلات الأندية.

## الفحوص المحلية

- `npm run typecheck`: ناجح.
- `npm run lint`: ناجح.
- `npm run build`: ناجح، بما في ذلك تجميع Next.js وتوليد الصفحات.
- `npm run test:all`: 278 اختبار وحدة ناجحًا، و7 اختبارات اختيارية متصلة بقاعدة البيانات متخطاة، و16 مجموعة تكامل ناجحة.

- فشل التشغيل الأول للاختبارات بسبب منع إنشاء العمليات الفرعية داخل العزل؛ بعد إعادة التشغيل المسموح بها نجحت المجموعة كاملة. وصُححت توقعات إصدار قديمة في اختبارَي Android.

## نتائج Supabase الحية — قراءة فقط

ظهرت بتاريخ 5 نوفمبر 2026:

- تحذيران أمنيان: امتداد `pg_net` موجود في schema `public`، وحماية كلمات المرور المسرّبة معطلة في Supabase Auth.
- 42 ملاحظة أداء لسياسات RLS حول إعادة تقييم `current_setting()`/دوال auth لكل صف.
- 6 مجموعات سياسات permissive متعددة، و7 فهارس بلا استخدام في إحصاءات الفترة.

لم تُحذف الفهارس، ولم تُغيّر سياسات RLS أو إعداد Auth مباشرة. أي تغيير في السياسات يتطلب migration مُراجعًا، واختبارات صلاحيات وعزل أندية على قاعدة اختبار قبل تطبيقه على الإنتاج. انظر روابط الإصلاح الرسمية في [مراجعة Supabase](SUPABASE_REVIEW_2026-10-28_AR.md).

## ما لم يُعتمد ميدانيًا

- تثبيت التطبيقات الثلاثة وتحديثها على أجهزة Android فعلية، واختبار صلاحيات الإشعار ووصول FCM بعد إغلاق التطبيق.
- تثبيت PWA على iPhone واختبار تنبيهات iOS، وتشغيل Windows WebView وهو في الخلفية.
- قارئ الباركود والبصمة والطابعة والكاميرا والسماعات على موديلات النادي الفعلية. اكتشاف الجهاز لا يثبت توافق SDK أو التعريف.
- استعادة نسخة قاعدة كاملة، واختبار تحميل متعدد الأندية، ووصول البريد وSMS/WhatsApp ومشغلات الموسيقى باستخدام حسابات ومزودين فعليين.
- قبول Authenticode لويندوز أو النشر في Microsoft Store.

لا تمثل نتيجة فحص الإصدارات أو نجاح الاختبارات البرمجية اعتمادًا تجاريًا للأجهزة أو مزودي الخدمة. لا تُرسل رسائل أو مدفوعات حقيقية في الاختبارات الآلية. لم تُنشأ Pull Request ولم تُرفع التعديلات أو تُنشر؛ هذا الفرع محلي للمراجعة.
