# GYMEG Android — management and members

GYMEG Members: `com.pushtorq.members`, `/member`. GYMEG Manager: `com.pushtorq.management`, `/clubs`. GYMEG Support: `com.gymos.support`, `/platform`. Firebase Messaging is added to all three Gradle app targets. The Firebase project is `gymeg-mobile-notifications` (sender ID `744394281001`). Current source versions are Manager 1.1.8 (versionCode 10), Members 1.1.7 (versionCode 9), and Support 1.0.6 (versionCode 7). Android 8+ and internet are required. On Android 12+, scheduled announcements require the user to allow exact alarms; the manager app asks when an enabled schedule is first synchronized. Native scheduling honors the gym timezone, recurrence, and device reboot. Browser playback is foreground-only and cannot guarantee background playback. iPhone continues to use the Safari Home Screen web app.

The current signing certificate is recorded in docs/identity/android-signing-certificates.json. The private key is stored locally under `.firebase-private/` and excluded from Git; keep an owner-only backup in a separate secure location. Manager 1.1.8 keeps the same signing certificate as 1.1.7 and can update it in place. If a future package changes its signing certificate, Android requires uninstalling the older app first; normal updates must retain this key and increment versionCode.

Firebase build: the checked-in `google-services.json` files are public Android client configuration and each matches its app ID/package; they contain no service-account private key. Install Gradle 8.x, JDK 17+, and Android SDK platform/build tools 36, then run `./build-firebase.ps1` for debug builds. Signed release builds use Gradle release tasks with `GYMEG_KEYSTORE`, `GYMEG_KEYSTORE_PASSWORD`, and `GYMEG_KEY_ALIAS`; run `node mobile-android/register-release-artifacts.mjs` with the verified certificate SHA-256 in `GYMEG_ANDROID_CERT_SHA256` to refresh APK metadata. The legacy `python mobile-android/build.py` build does not include Firebase SDK and must not be used for FCM-enabled APKs.

Manager camera access requires runtime consent and the trusted origin. The apps store FCM tokens locally; Manager/Members upload them only after the signed-in user enables alerts. Support enrollment is user-scoped. Native notification routes are restricted to the trusted GymEG origin, and no private chat text is included in FCM payloads. The apps have no file/content access, SSL bypass, third-party cookies, WebView debugging or app-data backup.

Firebase Gradle debug builds succeeded locally for all three apps. Real-device installation and push delivery have not been verified. The public Firebase client files are included in source; the sender credential is stored only as a sensitive Vercel variable. Production sending still requires deploying this source and exercising delivery on a physical Android device. The existing custom Android compiler does not support Firebase dependencies; use the Gradle build above.

References: https://developer.android.com/tools/apksigner and https://developer.android.com/tools/aapt2
